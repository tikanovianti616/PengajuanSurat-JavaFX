# Aplikasi Pengajuan & Tracking Surat Sekretariat (JavaFX)

Aplikasi desktop berbasis JavaFX untuk pengajuan surat, unduh dokumen PDF, dan verifikasi akses khusus bagi sekretaris.

## Fitur Utama
1. **Public User**:
   - Form Pengajuan Surat tanpa login.
   - Tracking & Unduh Surat berformat PDF.
2. **Sekretariat**:
   - Modal window Login Sekretaris (admin).

##  Tech Stack
- JavaFX & FXML
- Apache NetBeans IDE

## Cara Menjalankan
1. Ekstrak file `src.pengajuansurat.zip`.
2. Buka project di NetBeans.
3. Run `App.java` / class utama project.
